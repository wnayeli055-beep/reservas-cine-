## Objetivo del programa
Gestionar la reserva de asientos de una sala de cine pequeña de 3 filas × 4 columnas.
- `0` = asiento libre
- `1` = asiento reservado

El programa crea una matriz, solicita al usuario la fila y columna a reservar, marca el asiento y muestra el estado completo de la sala en formato de tabla utilizando bucles anidados.

## Cómo ejecutar el programa
1. Tener instalado Python 3
2. Abrir la terminal en la carpeta del archivo
3. Escribir el comando:
```bash
python reservas-cine.py
```
4.Ingresar la fila (0, 1 o 2) cuando se solicite
5.Ingresar la columna (0, 1, 2 o 3) cuando se solicite
6.Se mostrará el estado actualizado de toda la sala

## Características implementadas
Matriz creada como lista de listas
Entrada de datos con input() convertida a entero con int()
Recorrido y muestra de la matriz con bucles anidados
Variables descriptivas (fila, columna)
Código comentado para facilitar la comprensión
